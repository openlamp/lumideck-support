# LumiDeck — Support & Issue Tracker

Public support tracker for **LumiDeck**, a commercial Elgato Stream Deck plugin that
drives **WLED** lamps & strips — 100% local, over the WLED JSON API, no cloud.

> This repository holds **no source code** — LumiDeck is a proprietary product. It exists
> so you can **report bugs, request features, and ask questions** in the open.

## Get LumiDeck

- Elgato Marketplace — *coming soon*

## Report a problem / request a feature

Open an [issue](https://github.com/openlamp/lumideck-support/issues/new/choose) and pick
**Bug report** or **Feature request**. For bugs, please include:

- your OS (macOS / Windows) and Stream Deck model,
- your WLED firmware version and lamp/strip model,
- steps to reproduce, and what you expected vs. what happened.

## Disclaimer

LumiDeck is **not affiliated with or endorsed by** the WLED project or Elgato. "WLED" and
"Stream Deck" are used only to describe compatibility; LumiDeck interoperates with WLED
over its public local API.
